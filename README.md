# E-commerce Core

Реализация основных сущностей интернет-магазина.

## Функционал

- Класс `Product` для представления товаров
- Класс `Category` для представления категорий товаров
- Автоматический подсчет количества категорий и товаров
- Полная тестовая покрытие функционала

## Установка

1. Установите Poetry: https://python-poetry.org/docs/#installation
2. Установите зависимости: `poetry install`
3. Активируйте виртуальное окружение: `poetry shell`

### Классы-наследники
- **Smartphone**: Наследник Product с дополнительными атрибутами:
  - `efficiency` (производительность)
  - `model` (модель)
  - `memory` (объем памяти)
  - `color` (цвет)
- **LawnGrass**: Наследник Product с дополнительными атрибутами:
  - `country` (страна-производитель)
  - `germination_period` (срок прорастания)
  - `color` (цвет)

### Ограничения сложения
- Можно складывать только товары одинакового типа
- При попытке сложить разные типы выбрасывается `TypeError`

### Ограничения добавления в категорию
- В категорию можно добавлять только объекты класса `Product` и его наследников
- Используется `isinstance()` для проверки
