# E-commerce Core

Реализация основных сущностей интернет-магазина.

## Функционал

- Класс `Product` для представления товаров
- Класс `Category` для представления категорий товаров
- Автоматический подсчет количества категорий и товаров
- Полная тестовая покрытие функционала

## Установка

1. Установите Poetry: https://python-poetry.org/docs/#installation
2. Установите зависимости: `poetry install`
3. Активируйте виртуальное окружение: `poetry shell`

## Новая функциональность

### Режимы доступа к атрибутам
- Атрибут списка товаров класса `Category` стал приватным
- Реализован метод `add_product()` для добавления товаров
- Автоматическое обновление счетчика продуктов при добавлении

### Геттеры и сеттеры
- Геттер для приватного атрибута `products` возвращает форматированную строку
- Приватный атрибут цены в классе `Product` с геттером и сеттером
- Валидация цены на положительное значение

### Класс-методы
- Класс-метод `new_product()` для создания объектов из словаря
